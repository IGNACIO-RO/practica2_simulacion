# Práctica 2: Análisis del Tiempo de Atención en Cajas de Supermercado

## ¿De qué trata este proyecto?
Este proyecto analiza el tiempo que tardan los cajeros en atender a los clientes en un supermercado durante las horas de mayor movimiento. El objetivo es calcular datos estadísticos básicos (promedio, mediana, tiempos más lentos y rápidos) y detectar si hay cobros que demoraron demasiado usando la prueba del **Z-Score**.
